## About This Roadmap

This repository documents my 120-day self-study plan to become proficient in AI/ML development — starting from Python basics and progressing all the way to LLMs, embeddings, RAG, and AI agents. Each day includes focused topics, and every phase ends with a hands-on project to reinforce what was learned.

**Goal:** Build a portfolio of real, working AI/ML projects while developing a solid theoretical foundation.

---

## Learning Path Overview

```
Python → NumPy → Pandas → Mathematics → Statistics → Machine Learning
   → Scikit-learn → Deep Learning → PyTorch → NLP → Transformers
   → LLMs → Embeddings → RAG → AI Agents → Real AI Projects
```
